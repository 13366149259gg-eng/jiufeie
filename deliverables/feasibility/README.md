报告以附件中的场地基本情况为基础，以检索取得的官方文件和全国实际案例为技术依据，不使用附件推测投资收益或未核风险等级。18项官方文件、标准和案例及2项基础资料在Word附录、PPT备注和核算表中使用同一编号。

推荐以分区开挖为主体研究路线，近期维护保障、风险调查与主体准备并行；在移除堆体和核查修复场底目标下论证开挖必要性。开挖范围按调查、示范和审批核定。2027年国家节点针对符合条件的停用场封场治理，不解释为全量开挖统一时限。

详细方案包括调查、示范、降水位和气体预处理、分区分层、防渗集气、清污分流、膜浓缩液、全部产物去向、运输、监测停工、场底地下水修复、效果评估和后期管理。草案参数明确为技术参考，环境监测数值不作为人员安全阈值。

投资列13项工作包和计量核价条件。现有170吨/日与115元/吨折算713.575万元/年；10年和20年理想最高避免支出分别为7135.75万元、14271.5万元，不是项目收益预测。体积计价单项每变化10元/m³，对170万和250万m³口径分别影响1700万元、2500万元；变化步长非报价。主体投资、真实回收期和竣工工期在统一调查、示范、合法接收、实际报价及审批后核定，未定成本不按零元汇总。

日期基准为2026年10月11日；现有合同据资料至12月31日，日期差81天，安排到期前运行衔接。前30、90、180天为建议组织节点，不是审批或竣工承诺。
