## 统一测算口径

垃圾体量250万m³、湿密度0.85t/m³、湿质量212.5万吨为基准研究假设。
治理概算约11.66亿元；一体化筹资约21.59亿元。
水和浓缩液运行费由旧稿3000万元暂列调整为9324.13万元的量价情景。
污染防治专项直接费约2.29亿元为治理总概算子集，不重复追加。
稳态营业收入约1.116亿元/年；可偿债现金流约4175万元/年。
70%贷款方案稳态DSCR约0.39，首个运营年约0.27，不能支持原拟贷款规模。
工程组织目标约60个月；财务模型第8年达稳态，地下水跟踪可能更长。
